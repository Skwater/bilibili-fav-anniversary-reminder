# 哔哩朝花夕拾

> Chrome 扩展（Manifest V3）· 在哔哩哔哩首页提醒你收藏夹里“历史上的今天”发布的投稿。

> 🛒 **一键安装**：[Chrome 应用商店 · 哔哩朝花夕拾](https://chromewebstore.google.com/detail/kgamlldkccpldahaohnbnnfdnegphppe)（当前版本 v0.1.4）

打开 `https://www.bilibili.com/` 时，插件按你收藏夹内**视频投稿的发布时间**与今天（月-日）做匹配——如果若干年前的今天你收藏过某些投稿，右下角会弹出一张"X 年前的今天"卡片，点击可回到视频。

## 功能特性

- 📅 **历史上的今天**：打开 B 站首页时，浮层提示命中的历史投稿（发布时间月日 == 今天）
- 📚 **收藏夹管理**：读取“我创建的 + 我收藏(追更)的”全部收藏夹，按来源分组、可折叠、可勾选
- 🧭 **首次向导**：第一次使用先选择要同步的收藏夹（区分自建/追更）再开始
- ⚡ **智能增量**：差异检测 + 针对性同步——数目增加→增量补新、数目减少→全量清理，不做普查
- 🛡️ **风控克制**：页间隔/每段页数/暂停时长/412 冷却均可在「高级设置」调整；412 命中后冷却自动续传
- 🧪 **模拟日期**：随时用“模拟今天”验证任意日期的命中，无需等真日子
- 🔒 **隐私友好**：数据全部本地存储（chrome.storage.local），不读取/不存储 Cookie，不上传第三方

## 安装

**方式一：Chrome 应用商店（推荐）**

前往 [哔哩朝花夕拾 · Chrome 应用商店](https://chromewebstore.google.com/detail/kgamlldkccpldahaohnbnnfdnegphppe) 点「添加至 Chrome」，之后会自动更新。

**方式二：本地开发加载**

1. Chrome/Edge 打开 `chrome://extensions`，右上开启「开发者模式」；
2. 点「加载已解压的扩展程序」，选择本目录的 `extension/` 文件夹；
3. 打开并刷新 `https://www.bilibili.com/`，按首页浮层向导选择收藏夹开始同步。

> 说明：登录态来自你浏览器内已登录的 B 站会话；扩展自身不持有、不存储任何凭据。

## 使用速览

- **首次**：首页浮层出现“自选收藏夹”向导（我创建的 / 追更的分组）→ 勾选后开始全量
- **日常**：扩展图标 Popup 点「增量同步」即可（几乎零请求的差异检测）
- **范围**：增量/全量按钮旁可选 全部 / 仅我创建的 / 仅追更的
- **高级设置**（设置页最底部折叠区）：412 冷却、每段页数、配额暂停时长、模拟日期、清空数据
- **调试**：设置页「高级设置 → 模拟今天」设一个日期，首页浮层会显示该日期的命中与调试栏
